description: 15-minute finance class tied to the current Sanchaya module
---

Run a 15-minute finance class. Timebox it: if Chirag is still asking questions at 15 minutes,
answer the one open question and stop.

1. Check `git log -5` and `docs/roadmap.md` to find the module Chirag is on or about to reach.
   Pick the *one* finance concept that module needs (examples: Module 4 → point-in-time data
   and lookahead bias; Module 5 → what P/E, ROE, debt/equity actually predict in Indian mid-caps;
   Module 6 → RSI/MACD and why most indicators are noise; Module 10 → position sizing, sector
   caps, max drawdown; Module 15 → STT, brokerage, slippage, why costs kill most strategies).
   If the module has no finance content, teach the next concept from the pipeline's data flow.
2. Teach in this order: intuition → one worked numerical example using a real NSE stock →
   the formula → the failure mode (how this concept misleads people) → how it shows up in
   Sanchaya's code.
3. End with **two questions** Chirag answers in chat, in his own words. Correct him if he parrots.
   His answers are the record of the class; nothing is written to a file.
4. Note the concept and his two answers in memory for `/quiz` on Saturday.

Do not turn this into a lecture series. One concept, one example, two questions, done.
