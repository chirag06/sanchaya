Run the weekly test. Saturday, ~40 minutes, closed book.

1. Build the questions from this week's `/finance` classes, `/lld` classes and `/kata` sessions
   (from memory and from `learn/` posts committed this week). Ten finance, ten LLD. Mix: 4 recall
   ("what does X mean"), 4 application ("given this situation, what would you do and why"),
   2 that connect the concept to Sanchaya's actual code.
2. Ask one question at a time. Wait for the answer. Do not reveal the next question early.
3. Score each 0/0.5/1. Parroted definitions without understanding score 0.5 at most; say so.
4. Report: finance score /10, LLD score /10, the three weakest answers with a two-line correction
   each, and the single topic to re-teach in next week's first `/finance` or `/lld`.
5. Tell him to report both scores in Monday's lead meeting; they go in the status doc.

Nothing is written to a file. The scores live in the status doc via the morning meeting.
